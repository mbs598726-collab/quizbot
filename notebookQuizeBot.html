Concept 01

📋 Lists

What is a List?

A list is an ordered collection that holds many values in a single variable. Instead of creating question1, question2, question3… you create one questions list and access items by their position (index).

Real-Life Analogy

Think of a shopping list. You write items in order — milk, eggs, bread. The first item is at position 0, the second at position 1, and so on. You can add items to the end, count them, or pick one by its number.

Why It Matters

Lists are everywhere in programming. In the Quiz Master Bot, the entire question bank is a list — each item is a dictionary containing a question and its answer. Without lists, you'd need separate variables for every question, making the code impossible to grow.

Worked Code Example

day1.py — Creating and using a list 
# A list of fruits
fruits = ["apple", "banana", "cherry"]

print(fruits)        # ['apple', 'banana', 'cherry']
print(fruits[0])     # apple  (first item)
print(fruits[1])     # banana (second item)

# Add an item to the end
fruits.append("orange")
print(fruits)        # ['apple', 'banana', 'cherry', 'orange']
print("Number of fruits:", len(fruits))  # 4
⚠️ Pitfall — Index Starts at 0 The first item is at index 0, not 1. This trips up every beginner once. fruits[0] is "apple", fruits[1] is "banana".
💡 Pro Tip Use len(list) to count items and list.append(item) to add to the end. These two operations cover 90% of everyday list usage.
Concept 02

📖 Dictionaries

What is a Dictionary?

A dictionary stores data in labeled pairs — a key and its value. Instead of accessing data by position (like lists), you access it by a meaningful name.

Real-Life Analogy

Think of a contacts app. You don't remember phone numbers by their position — you look up "Mom" and get her number. The name is the key, the number is the value.

Why It Matters

In Quiz Master Bot, each question is a dictionary with keys like "question", "options", and "answer". This makes the code self‑documenting: q["question"] is instantly clear, whereas q[0] would be a mystery.

Worked Code Example

day3.py — Your first dictionary 
# A simple dictionary mapping countries to capitals
capital = {"France": "Paris", "Japan": "Tokyo"}

print(capital["France"])   # Paris
print(capital["Japan"])    # Tokyo

# A quiz question stored as a dictionary
q1 = {
    "question": "What is 2 + 2?",
    "answer": "4"
}
print(q1["question"])         # What is 2 + 2?
print("Correct:", q1["answer"]) # Correct: 4
⚠️ Pitfall — KeyError If you ask for a key that doesn't exist, Python raises KeyError. Always double‑check your spelling: q["answer"] not q["answers"].
💡 Pro Tip The "list of dictionaries" pattern — a list where each item is a dictionary — is used in every real program that deals with records (users, products, questions). It's one of the most valuable structures you'll ever learn.
Concept 03

🔁 Loops

What is a Loop?

A for loop repeats a block of code once for each item in a collection. It's how you avoid writing the same code over and over for every question.

Real-Life Analogy

Imagine a teacher going through a stack of exam papers. For each paper: read the name, check the answers, write the score. The teacher doesn't need separate instructions for paper 1, paper 2, paper 3 — they follow the same process for every paper. That's a loop.

Why It Matters

The Quiz Master Bot loops through the question bank, asks each question, checks the answer, and updates the score. Add 100 more questions? The loop still works — zero extra code.

Worked Code Example

day5.py — Loop and check answers 
# The question bank (list of dictionaries)
questions = [
    {"question": "What is 2 + 2?", "answer": "4"},
    {"question": "Capital of Japan?", "answer": "Tokyo"},
]

# Loop through every question
for item in questions:
    user_answer = input(item["question"] + " ")

    if user_answer == item["answer"]:
        print("Correct!")
    else:
        print("Wrong. The answer was", item["answer"])
⚠️ Pitfall — Indentation The code inside the loop must be indented. If you forget, it runs only once. Python uses indentation to define blocks — it's not optional.
Concept 04

🏆 Scoring & Feedback

What is Scoring?

A score is just a number that starts at zero and increases by one each time the player answers correctly. At the end, you show the final score and a friendly message.

Real-Life Analogy

Think of a basketball game. Every time a player scores a basket, the scoreboard ticks up by 2 or 3. At the end, the final score tells everyone how the game went. Same idea here — one point per correct answer.

Why It Matters

Without scoring, the quiz is just a series of questions. Scoring turns it into a game — it gives the player feedback, motivation, and a reason to try again.

Worked Code Example

day8.py — Adding a score counter 
score = 0  # Start at zero

for item in questions:
    user_answer = input(item["question"] + " ")

    if user_answer == item["answer"]:
        print("Correct!")
        score = score + 1  # Or: score += 1
    else:
        print("Wrong. The answer was", item["answer"])

# This line must be OUTSIDE the loop (same indent as "for")
print("Quiz over! You scored", score, "out of", len(questions))
⚠️ Pitfall — Indentation of the Final Print The final print must not be indented under the loop. If it is, it prints after every question instead of once at the end.
💡 Pro Tip Use score += 1 as a shortcut for score = score + 1. It's cleaner and less error‑prone.
Concept 05

💾 Files & JSON Persistence

What is File Persistence?

Normally, when a program closes, all data disappears. File persistence means saving data to a file on disk so it survives between runs — like a leaderboard that remembers every player's score.

Real-Life Analogy

Think of a notebook vs. a whiteboard. The whiteboard is wiped clean every day (like program memory). A notebook keeps your notes forever (like a file on disk). The Quiz Master Bot uses a scores.json file as its notebook.

Why It Matters

Without files, every quiz session starts from zero. With files, you can build a leaderboard that compares players across days, weeks, or months. This is your first taste of real data persistence — a concept used in every app you've ever used.

Interactive: Write, Read, and Append

Simulate file operations

"w" mode erases the file first, then writes. Use it only when you want a fresh start.

// scores.txt before:
Sam scored 3
Alex scored 5
// After open("scores.txt", "w") and write("New score\n"):
New score
// Old lines are gone!

"a" mode adds to the end without erasing. This is what you use for a leaderboard.

// scores.txt before:
Sam scored 3
Alex scored 5
// After open("scores.txt", "a") and write("New score\n"):
Sam scored 3
Alex scored 5
New score
// Old lines are safe!

"r" mode reads the file. Use .readlines() to get a list of every line.

// scores.txt contents:
Sam scored 3
Alex scored 5
New score
// file.readlines() returns:
["Sam scored 3\n", "Alex scored 5\n", "New score\n"]
// A list of strings — one per line!

Worked Code Example

day15.py — Writing and appending to a file 
# Write mode: erases the file first
file = open("scores.txt", "w")
file.write("Sam scored 3\n")  # \n = new line
file.close()  # Always close so it saves properly

# Append mode: adds without erasing
file = open("scores.txt", "a")
file.write("A new score line\n")
file.close()

# Read mode: read all lines back
file = open("scores.txt", "r")
lines = file.readlines()
file.close()
for line in lines:
    print(line.strip())  # strip() removes the \n
⚠️ Pitfall — Forgetting to Close If you don't call .close(), the file may not save properly. Use with open(...) as file: to close automatically.
💡 Pro Tip — JSON is Better for Structured Data The final Quiz Master Bot uses JSON instead of plain text. JSON stores data as a list of dictionaries, making it easy to save and load scores with json.dump() and json.load().

Recap

Key Takeaways & What's Next

📋 Lists

Ordered collections. Access by index (starts at 0). Add with .append(). Count with len().

📖 Dictionaries

Key–value pairs. Access by meaningful key, not position. Perfect for storing records with named fields.

🔁 Loops

Repeat code for each item in a collection. Indentation matters. The heart of any quiz program.

🏆 Scoring

A counter that starts at 0 and increments on success. Percentage = (correct / total) × 100.

💾 File Persistence

Save data to disk so it survives between runs. Use "a" to append, "w" to overwrite, "r" to read.
